Basic Route

Service version: 1 · Last edit: 2026.09.14 Routing API v1.22

The Basic Route endpoint calculates the shortest or fastest route between two or more waypoints. The response includes a summary, legs, and the route geometry encoded as a GeoJSON LineString.

The response waypoint count reflects the number of route legs, not the number of input locations. A route between two points returns one leg with a start and end point.

Sample request

The following example calculates a driving route from Amsterdam to Rotterdam, with default traffic settings applied.

GET https://api.tomtom.com/routing/1/calculateRoute/
    52.3731,4.8922:51.9225,4.4792/json
    ?key={API_KEY}
    &travelMode=car
    &traffic=true

Sample response

The response returns a routes array. Each route object contains a summary and one or more legs.

{
  "routes": [{
    "summary": {
      "lengthInMeters": 78432,
      "travelTimeInSeconds": 3612,
      "departureTime": "2026-09-14T09:00:00+02:00"
    },
    "legs": [{
      "summary": { ... },
      "points": [
        { "latitude": 52.3731, "longitude": 4.8922 },
        { "latitude": 51.9225, "longitude": 4.4792 }
      ]
    }]
  }]
}

Rendering the route

Pass the points array from each leg to the Map Display API to render the route geometry as a polyline on the map.
